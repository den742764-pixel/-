# Sirius v22 / 1.15.0

## Проверка запуска и совместимости интерфейса

- Добавлен `runtime-smoke-test.js` в `npm test`.
- Тест запускает отдельный процесс сервера с временной базой и проверяет готовность `/api/ping`, HTTP 200 для главной страницы, базовые security-заголовки и CSP.
- Проверяется, что SHA-256 хэши встроенного JavaScript совпадают с CSP, а встроенный скрипт разбирается Node.js без синтаксических ошибок.
- Автоматически сверяются литеральные API-маршруты, используемые интерфейсом, с маршрутами, объявленными сервером.
- Проверяются отказ для неавторизованного запроса, запрет неправильного Content-Type и HTTP 404 неизвестного маршрута.
- README обновлён до текущей версии.

## Границы проверки

Автотесты не заменяют проверку звонков между реальными устройствами, push-уведомлений в конкретном браузере/Android, TURN через вашу сетевую инфраструктуру, реального платёжного провайдера и развёртывания за вашим reverse proxy. Эти функции зависят от внешней конфигурации и устройств.
