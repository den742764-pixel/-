# Sirius v17 / 1.10.0 — 19.10.2026

## Исправления безопасности

- **Приватность номера телефона:** если в старых данных профиля есть `ph` и включён `fph`, номер теперь выдаётся только подтверждённым друзьям. Посторонний пользователь больше не получает номер из начального состояния SSE или обновления профиля.
- **Скрытие времени последней активности:** при `invisible: true` поле `seen` не передаётся другим пользователям. Сам владелец продолжает видеть собственное значение.
- **Антиспам личных сообщений и групп:** новые сообщения ограничены 40 сообщениями в минуту на аккаунт и 15 сообщениями в минуту в одном допустимом диалоге/группе. Проверка выполняется на сервере, в том числе для `update` с несуществующим ID.
- **Защита лимитера от мусорных ключей:** per-conversation лимитер создаётся только для канонического личного диалога с реальными участниками или существующей группы, где отправитель имеет право писать.
- Сервер проверяет структуру E2E-конверта v2 (версия, соль, IV и размер шифротекста), а для старого формата v1 проверяет допустимый размер бинарного шифротекста. Сообщения с произвольным текстом под видом шифротекста отклоняются.
- Добавлен отдельный регрессионный тест для телефонной приватности и скрытия last-seen, а также тест на отклонение некорректного E2E-конверта.

## Проверки

- `node --check server.js`
- `node --check security-smoke-test.js`
- `node --check security-profile-privacy-test.js`
- `npm test` — все тестовые программы пройдены, включая новую проверку приватности и тест лимита сообщений.

## Область действия

Изменения исправляют два конкретных нарушения приватности и добавляют серверное ограничение частоты сообщений. Они не заменяют независимый аудит всей системы и не изменяют архитектуру криптографического протокола E2E.
