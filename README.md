# Sirius v24 — UI preview images

These are static visual mockups of the intended mobile layout for the two built-in assistant chats and Sirius Premium. They are design previews, not captures from a live authenticated session. The actual app UI is implemented in `index.html`; the backend flows are covered by `premium-bots-test.js`.

- `01-chats-bots.png` — chat list with Support and Stars/Premium bots pinned at the top.
- `02-premium-shop.png` — Premium purchase screen and benefits.
- `03-premium-bot.png` — Stars/Premium bot conversation and actions.
