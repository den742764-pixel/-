# Release checklist v23

- [ ] На хостинге задан уникальный `DEV_CODE` длиной не менее 32 символов.
- [ ] Войти в приложение, открыть «Код разработчика» и ввести `DEV_CODE`.
- [ ] В магазине → Владелец → Настроить реквизиты сохранить реальные реквизиты.
- [ ] Создать тестовую заявку под обычным аккаунтом и проверить, что реквизиты и номер заказа показаны корректно.
- [ ] Под аккаунтом владельца подтвердить тестовую заявку только после проверки поступления денег.
- [ ] Убедиться, что повторное подтверждение не начисляет звёзды повторно.
- [ ] Перед реальными платежами проверить правила банка/провайдера и требования к приёму платежей.
